# PostgreSQL format-matrix corpus

TEXT/JSON/YAML captures of the same `EXPLAIN` per query shape, for every
PostgreSQL major version 12…18. Generated by `tools/gen-fixtures.sh`
(throwaway Docker containers, official `postgres` images) and committed.

`test/parity.test.js` asserts that all three formats of a shape normalize
to the same tree and planner estimates through the current pipeline.
Shapes that execute DML (`merge`, `triggers`, `wal`) are compared
structure-only: each format capture is a separate execution, physical
table size drifts between runs, and the planner extrapolates frozen
statistics onto the current size.

Regenerate everything, one version, or a shape subset:

```bash
tools/gen-fixtures.sh
VERSIONS="18" tools/gen-fixtures.sh
VERSIONS="12 13" ONLY="triggers wal" tools/gen-fixtures.sh
```

Do not edit these files by hand.
